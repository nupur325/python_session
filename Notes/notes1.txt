Exception Handling, Multithreading:
Exception: 
An exception is an error that occurs during program execution. Exception handling allows a program to continue running without crashing unexpectedly.
When a python script encounters a situation that it cannot cope with, it raises an exception.
An exception is a python object that represents an error.
Exception handling in Python refers to managing runtime errors that may occur during the execution of a program.

*ADVANTAGES:
1. Prevents abnormal termination
2. Improves program reliability

COMMON EXCEPTIONS:

*Try: The try block lets you test a block of code for errors.
*Except: The except block lets you handle the error.
*Else: The else block lets you execute code when there is no error.
*Finally: The finally block lets you execute code, regardless of the result of the try-and except blocks.

Multithreading:
A light weight process that performs a specific task within a program.
A thread is the smallest unit of execution in a process. 
Allows you to run multiple threads concurrently within a single process

Thread life cycle in python:
New - thread is created but not yet started. It has been allocated resources but its not executing
Running - A thread is started and currentlyl executing it code
Blocked - A thread is waiting fir an event or condition to occur, such as waiting for I/O operation
Terminated - A thread has completed its execution or has been explicitly Terminated

Key functions:
start() - begin thread execution
sleep() - pause thread (import from asyncio/datetime)
join() - wait for thread 
thread() - create thread 

sleep() vs join()
            sleep()                                     Join()
    pauses current thread                      waits for another thread
    takes time as argument                     takes thread object
    used for delay                             used for synchronization 

Lock:
A lock is a synchronization mechanism provided by the threading module that allows one thread to access
a shared resource at a time.
It Prevents race condition and ensures data consistency when multiple threads work on same data.

Create lock:
    lock = threading.Lock
acquire():
    lock.acquire()
    if the lock is free, the thread acquires it.
    if another thread already holds it, the thread waits.
release():
    lock.release()
    other waiting thread can now acquire the lock

Working of lock:
Thread1 -> acquire() -> Critical section -> release()
Thread2 -> waits until lock is released
Thread2 -> acquire() -> Critical section -> release()
