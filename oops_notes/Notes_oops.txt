types of data member
1. Instance data member - 
    declared using self.
    each object gets it own Copy 
    changes in one object do not affect other object

2. Class data members - 
    declared inside the class but outside methods
    shared by all the objects of the class
    only one copy exists(if changes are made it will be refelected to all)

3. Private data members
    begin with double underscore(_)
    cannot be directly accessed outside the class
    used for data hiding and encapsulation
        set using setter method
        get using getter method

Constructor (__init__): a special method automatically called when an object is created. 
    it is used to initialze instance variables
    Uses:
        initialize object data
        assign default values
        open files or database connections
        prepare object for used
    Types -
        Default - no parameters except self
        Parametererized - Accepts additional parameters

Destructor (__del__): a special method automatically called when an object is destroyed. 
    It is used to release resources such as files, network connections ,etc.

@classmethod
a class method is a method that operates on class variables rather than instance variables.
It is defined using the @classmethod decorator and accepts cls as its first parameter.
It is a decorator that tells Python that the method belongs to the class rather than any specific object.
cls -> class

            self                                            cls
        refers to current object                        refers to current class
        used in instance methods                        used in class methods
        object required to call method                  can be called using class name
        accesses instance variables                     accesses class variables
